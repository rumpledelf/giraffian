# Pixel picture library

Eighteen original compositions generated with the built-in imagegen tool, then reduced to 12×12, 20×20, 28×28, 48×48 and 100×100 grids. Every cell is opaque and uses one of three to ten fixed palette colours. No dithering. The PNG files are the final 100×100 artwork; pictures.js contains every playable size.
